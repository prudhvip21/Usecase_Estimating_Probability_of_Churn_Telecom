# Telecom Customer Churn Prediction

Estimate which telecom customers are likely to leave, so retention teams can act early.

## Approach

- Exploratory analysis of customer and service features
- Logistic Regression, Decision Tree, KNN, Random Forest, Naive Bayes and SVM
- Gradient boosting with XGBoost and LightGBM

## Results

Accuracy between about 0.72 and 0.80 in the saved notebook output.
